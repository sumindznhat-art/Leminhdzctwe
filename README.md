# 🎯 SUNWIN VIP TOOL

Công cụ phân tích Tài/Xỉu dựa trên **Ensemble 8 tầng thuật toán**.

## 📁 Cấu trúc

- `index.html` – Giao diện chính
- `style.css` – Toàn bộ style
- `algorithm.js` – Module thuật toán (tách riêng)
- `app.js` – Logic UI
- `vercel.json` – Cấu hình bảo mật & cache
